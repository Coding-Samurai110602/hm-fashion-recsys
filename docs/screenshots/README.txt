Screenshots require the API server running against the real bundle.

To capture screenshots:
1. make api  (in one terminal, real bundle)
2. make frontend-dev  (in another terminal)
3. Open http://localhost:5173 in a browser
4. Capture pages manually or with a tool like Playwright
